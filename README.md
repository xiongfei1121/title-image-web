# 🐻老熊标题图片生成器

免费在线标题图片生成工具，支持多行文字自动排版。

## 功能特点

- 支持 2-4 行文字自动生成标题图片
- 自动计算字号和间距，让文字撑满宽度
- 支持自定义文字颜色和背景颜色
- 支持自定义图片宽度
- 支持自定义每行字号

## 技术栈

- Nuxt 3
- Vue 3
- TailwindCSS
- Pinia

## API

本项目调用后端 API 生成图片

## 本地开发

```bash
npm install
npm run dev
```

## 构建部署

```bash
npm run generate
```
